# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's [private vulnerability reporting](https://github.com/Roastbook/open-coffee-schema/security/advisories/new) ("Report a vulnerability" on the Security tab). Do not open a public issue.

Relevant issues include: a way to make the Schema Explorer or Playground run script from crafted input, a compromised or tampered schema file at `https://schema.roastbook.coffee/`, a problem in the release workflow or the npm package `@roastbook/open-coffee-schema`, or leaked credentials.

We aim to acknowledge reports within five working days and to publish a fix and an advisory once it is resolved. We credit reporters who wish to be named.

## Supported versions

Only the newest release of the npm package and the current Schema Explorer are maintained. Published schema files are immutable; a problem in one is fixed by a new version.
